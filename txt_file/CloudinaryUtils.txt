**CloudinaryUtils.java**

**Purpose:**
This class provides utility functions for interacting with the Cloudinary service, which is a cloud-based platform for managing images and other media assets.

**How it works:**
The class is designed as a Spring `@Component`, allowing it to be easily injected and used throughout the application.

- **Initialization:**
  - The constructor `CloudinaryUtils(String cloudName, String apiKey, String apiSecret)` initializes the Cloudinary client with the necessary credentials (cloud name, API key, and API secret).
  - It configures a default asset folder named `"question_images"` where all uploaded files will be stored.

- **`upload(String fileName)` method:**
  - This method takes a file path (`fileName`) as input.
  - It uploads the specified file to the Cloudinary cloud.
  - Upon successful upload, it returns a `String` array containing two important pieces of information:
    1.  `public_id`: A unique identifier for the uploaded asset in Cloudinary.
    2.  `secure_url`: The HTTPS URL to access the uploaded file.

- **`delete(List<String> publicId)` method:**
  - This method takes a list of `public_id` strings.
  - It sends a request to the Cloudinary API to delete the corresponding assets from the cloud.

**Usage:**
This utility is used for managing media files, likely for questions that include images. It allows the application to upload images when creating questions and delete them when they are no longer needed, keeping the media assets synchronized with the application's data.
