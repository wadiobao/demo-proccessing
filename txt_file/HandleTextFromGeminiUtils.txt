**HandleTextFromGeminiUtils.java**

**Purpose:**
This class serves as a specialized parser and data extractor for responses received from Google's Gemini AI models. When interacting with an AI, the output can be either semi-structured text or a formal JSON object. This utility provides methods to handle these different formats and convert them into clean, usable Java objects.

**How it works:**
The class is a Spring `@Component`.

- **`parseQuestions(String inputText)` Method (Regex-based Parsing):**
  - **Scenario:** This method is designed for a specific, human-readable text format that follows a strict pattern but isn't JSON. It's likely used with older prompts or models that produce less structured output.
  - **Mechanism:**
    1. It defines a complex Regular Expression (`Pattern`) tailored to a Vietnamese question format: `"{Câu hỏi [id]: [text] A. [ans] B. [ans] C. [ans] D. [ans] Đáp án đúng: [X] Giải thích: [explanation]}"`.
    2. The regex uses capturing groups `(...)` to isolate each piece of information (the question ID, the question text, each answer option, the correct answer letter, and the explanation).
    3. It creates a `Matcher` to find all occurrences of this pattern within the `inputText` from Gemini.
    4. For each match found, it extracts the captured groups, creates `Answer` and `Question` objects, and adds them to a list.
    5. It includes basic error handling to prevent the entire process from failing if one question block is malformed.
  - **Use Case:** Best for legacy prompts or situations where the AI's output is consistent but not in JSON format. It's more brittle than JSON parsing.

- **`parseQuestionsV4(String inputText)` Method (JSON-based Parsing):**
  - **Scenario:** This is a more modern and robust approach, designed for prompts where the AI has been instructed to return a clean JSON array of question objects.
  - **Mechanism:**
    1. It first calls `extractJsonArrayString()` to "clean" the raw response, stripping away any introductory text or code block markers (like ```json ... ```) and leaving only the `[...]` part.
    2. It then uses Google's **Gson** library, a powerful tool for converting JSON to Java objects.
    3. `gson.fromJson(clean, questionListType)` automatically maps the fields from the JSON objects in the array to the fields in the `Question` and `Answer` DTOs.
  - **Use Case:** This is the preferred method when you can rely on the AI to generate valid JSON, as it's more reliable and easier to maintain than regex.

- **`extractJsonArrayString(String rawInput)` Static Helper Method:**
  - A simple but effective utility to find and extract the content between the first opening square bracket `[` and the last closing square bracket `]` of a string.
  - This is necessary because sometimes the Gemini API might wrap its JSON output with other text (e.g., "Sure, here is the JSON array you requested: [...]").

- **`extractDataFromGemini(GenerateContentResponse response)` Static Helper Method:**
  - **Scenario:** This method is used when the Gemini model is asked to generate a file (like an image) directly. In such cases, the file data is embedded within the API response object itself.
  - **Mechanism:**
    1. It takes the official `GenerateContentResponse` object from the Gemini client library.
    2. It parses the JSON structure of this response. The path to the data is typically nested deep inside: `candidates[0].content.parts[...]`.
    3. It iterates through the `parts` array to find the specific part that contains `"inlineData"`.
    4. From the `inlineData` object, it extracts the `data` field, which holds the file content encoded as a **Base64 string**.
  - **Use Case:** Essential for multimedia generation prompts, allowing the application to receive and process a generated image or other file directly from the response.

**Overall Usage:**
This utility class is a critical bridge between the raw output of the Gemini AI and the application's structured data models (`Question`, `Answer`, etc.). It handles the "dirty work" of parsing and data extraction, allowing the rest of the application to work with clean, predictable Java objects.
