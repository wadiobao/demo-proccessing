       participant Client
         participant QuizController

         participant PDFProcessingService

        Client->>+QuizController: POST /api/handlepdf (file, params)
        Note right of Client: Tải lên file PDF và các tham số
        QuizController->>+QuizService: handlePdf(file, params)
        QuizService->>+PDFProcessingService: extractTextFromPdf(file)

        QuizService->>QuizService: combinePrompt(params, extractedText)
        Note right of QuizService: Tạo prompt cho AI
        QuizService->>+GeminiAIService: generateQuestionWithGemini(prompt)
        GeminiAIService-->>-QuizService: return GeminiResponse (JSON string)
        QuizService->>QuizService: Parse JSON to List<Question>
        alt For each question with imgPrompt
            QuizService->>+GeminiAIService: generateImageWithGemini(imgPrompt)
            GeminiAIService-->>-QuizService: return imageUrl
            QuizService->>QuizService: Update Question with imageUrl
        end
        QuizService->>+FileGenerationService: generateWordAndPdfBase64(questions)
        FileGenerationService-->>-QuizService: return [wordBase64, pdfBase64]
        alt User is Authenticated
            QuizService->>+PdfStoreService: save(pdfStoreData)
            PdfStoreService->>+MongoDB: Insert document
            MongoDB-->>-PdfStoreService: Success
            PdfStoreService-->>-QuizService: Success
        end
        QuizService-->>-QuizController: return FileGenerateResponse
        QuizController-->>-Client: 200 OK (response: questions, wordBase64, pdfBase64)
